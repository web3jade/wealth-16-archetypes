# 财富16型 H5 首屏 Layout Spec

参考设计稿：928 × 1664 px（纵向）
用途：供 Cursor 实现响应式 HTML/CSS。以下为参考比例与建议值，不是原始设计文件中的精确测量值。

## 画布与整体风格
- 设计基准：928 × 1664
- 主背景：浅蓝渐变，建议 `#DCEAFF` → `#BFDFFF` → `#D8E9FF`
- 主标题渐变：`#2454B7` → `#2679FF` → `#12B5E8`
- 正文蓝灰：`#526B99`
- CTA 渐变：`#3476FF` → `#12B8E8`
- CTA 文字：`#FFFFFF`
- 页面应允许纵向滚动；不要把整张设计稿当背景图。

## 人物图片
- 六个人物素材由项目方提供，继续使用现有图片。
- 建议每个人物独立透明 PNG/WebP。
- `object-fit: contain`，底部对齐。
- 人物高度根据原图比例分别调整，不要强制裁切。
- 标签顺序：EVAP / ESMP / LVAF / LSAF / EVMP / LSAP。
- 中文名称：火箭推进器 / 堡垒架构师 / 破局狂想家 / 云端漫步者 / 复利极客 / 传承园丁。

## 响应式建议
- 以 390px 宽手机为主要适配目标。
- 使用 `clamp()`、百分比和 CSS Grid/Flex，不要照搬 928px 的固定宽度。
- 六个人物在窄屏可采用横向紧凑排列；若标签不可读，允许人物区横向滚动，但首屏视觉需保持完整。
- 适配 `env(safe-area-inset-top)`。
- CTA 必须连接项目现有测试入口，不要只做静态按钮。

## 素材文件
- `growth-arrow.svg`：半透明增长箭头
- `coin-left.svg` / `coin-right.svg`：金币装饰
- `sparkles.svg`：星光装饰
- `bg-curves.svg`：底部弧形背景装饰

这些 SVG 是可编辑的矢量近似素材，便于在 Cursor 中调整颜色、大小和透明度；它们不是从参考图中无损抠取的原始图层。
