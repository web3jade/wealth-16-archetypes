# 财富16型 (Wealth 16 Type)

Share-first retirement mini-app for **global** markets. Estimates readiness and reveals a **16-type (4-letter)** retirement personality social card.

## Run

```bash
npm install
npm run dev
npm test
npm run build
```

## What’s included

- **Wizard** — locale → life stage → money → lifestyle → risk → results
- **Engine** — nest egg projection, gap, extra monthly savings, sensitivity
- **Markets** — Asia + Americas + Europe + Oceania + Middle East + worldwide fallback (educational lite models)
- **Personality** — E/L · S/V · M/A · P/F → 16 archetypes
- **Share** — Share to X, copy plan brief for AI agents, PNG download

## Design Flow

UX prototype: [`.design-flow/retirement-planner/flow.yaml`](.design-flow/retirement-planner/flow.yaml)
